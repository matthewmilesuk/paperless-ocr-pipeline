1. Steps to do in the Google Cloud Console

These can't be automated from here -- do them in order, in the GCP console:

  1. Create a GCP project (or pick an existing one). Note its project ID (not its display name) -- you'll need it below.
  2. Enable billing for that project. Document AI won't work without a billing account attached, even within any free tier.
  3. Enable the Document AI API for that project.
  4. Create a Document AI processor -- choose the "Document OCR" (Enterprise Document OCR) processor type. Note the processor ID shown on its details page (not its display name) -- you'll need it below.
  5. Create a service account for this app (not your personal account), grant it the Document AI API User role (roles/documentai.apiUser) on the project -- least privilege, not project owner -- then create and download a JSON key for it. You'll upload that key file below.
